# 📊 Student Academic Performance & Fee Management Dashboard

## 🚀 Project Overview
This project is an interactive Excel dashboard built to analyze student academic performance, departmental results, fee collection status, admission trends, and demographic distribution. It serves as an end-to-end data analytics project utilizing advanced Microsoft Excel features.

## 🛠️ Tools & Techniques Used
- *Data Cleaning & Preparation:* Structured raw records into clean Excel Tables.
- *Data Analysis:* Created multiple *Pivot Tables* to aggregate and summarize data.
- *Data Visualization:* Designed professional *Pivot Charts* (Column Charts, Pie Charts, Line Charts, and Stacked Bar Charts).
- *Interactivity:* Integrated dynamic *Slicers* connected across all pivot tables using *Report Connections*.

## 📊 Key Insights Derived
1. *Department Performance:* Identified top-performing departments based on average student percentages.
2. *Fee Tracking:* Monitored paid vs. pending fee statuses to track institutional revenue.
3. *Admission Trends:* Analyzed year-over-year admission growth.
4. *Demographics:* Evaluated city-wise and gender-wise student distribution.
